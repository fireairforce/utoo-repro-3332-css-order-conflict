# Issue #3332: conflicting CSS output effects

This is a minimized reproduction derived from the Simple App generated by:

```bash
npx create-umi@4.7.9 repro-3332-css-order-conflict
```

It keeps one Umi application entrypoint and two lazy route chunks. Both chunks
import the same two CSS files, but in opposite orders. With
`@utoo/pack@1.5.13`, both ordered CSS chunks receive the same output identity
despite having different content.

## Reproduce

Use Node.js 20 or newer, then run:

```bash
npm install
npm run dev
```

Startup fails before the server becomes ready:

```text
TurbopackInternalError: conflicting effects for the same key
    at async EndpointImpl.writeToDisk (.../@utoo/pack/cjs/core/project.js:485:20)
    at async writeEntrypointToDisk (.../@utoo/pack/cjs/core/hmr.js:253:24)
    at async Promise.all (index 0)
    at async handleEntrypointsSubscription (.../@utoo/pack/cjs/core/hmr.js:417:17)
```

As a control, change the `@utoo/pack` override in `package.json` from `1.5.13`
to `1.5.12`, reinstall, and run `npm run dev` again. The server starts normally.

Related issue: https://github.com/utooland/utoo/issues/3332
